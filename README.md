# CineApp - Catálogo de Filmes

**Nome:** Beatriz Hermenegildo Egen

**RA:** 2991392513015

## Descrição

O **CineApp** é uma aplicação mobile desenvolvida em React Native com Expo para apresentação e interação com um catálogo de filmes.

A aplicação permite visualizar filmes cadastrados, consultar informações como título, gênero, ano e sinopse, acessar uma tela de detalhes e marcar filmes como favoritos.

O projeto utiliza componentes reutilizáveis, Props, `useState`, `useEffect`, `Pressable`, Flexbox, StyleSheet e Expo Router para navegação entre as telas.

## Funcionalidades

- Tela inicial com nome, imagem e descrição do aplicativo;
- Acesso ao catálogo de filmes;
- Catálogo com filmes cadastrados;
- Exibição de título, gênero, ano e imagem;
- Sistema de favoritos;
- Tela de detalhes do filme;
- Tela "Sobre";
- Navegação entre as telas utilizando Expo Router;
- Botões e elementos interativos utilizando Pressable.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
